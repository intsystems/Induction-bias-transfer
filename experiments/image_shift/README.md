# Инвариантность MLP к сдвигу изображения

Классификация MNIST обычным MLP с двумя скрытыми слоями ReLU, без свёрток.
Изображения размером 28×28 разворачиваются в вектор, пиксели масштабируются
в `[0, 1]`. Аугментация задана заранее; учитель не используется.

```text
loss = cross_entropy(f(x), y) + weight * mean(abs(f(x) - f(shift(x))))
```

`f(x)` — десять логитов до softmax. Штраф усредняется по объектам и классам,
градиенты проходят через оба предсказания. Cross-entropy считается на исходных
изображениях. При `weight=0` получается baseline без регуляризации.

На каждом шаге для каждого изображения независимо выбираются целочисленные
сдвиги по вертикали и горизонтали из `[-max_shift, max_shift]`, включая нулевой.
По умолчанию `max_shift=3`. Освободившиеся пиксели заполняются нулями,
вышедшие за границы обрезаются. Предполагается, что небольшой сдвиг сохраняет класс.

Для всех весов штрафа совпадают выборки, начальные веса MLP, порядок батчей
и последовательность обучающих сдвигов. На тесте используется фиксированный
случайный сдвиг каждого изображения. Оценка проводится батчами.

По умолчанию: 2000 train-примеров, 10000 test-примеров, два скрытых слоя
по 128 нейронов, 20 эпох, веса штрафа `0`, `0.1`, `0.5`, `1`, `3`.
Используется CUDA; для CPU передайте `--device cpu`.

Зависимости: `torch`, `torchvision`, `matplotlib`. Команды из корня репозитория:

```bash
python experiments/image_shift/experiment.py
python experiments/image_shift/plot_results.py
```

При первом запуске MNIST скачивается в `data`. Результаты по умолчанию:
`results/image_shift/metrics.json` и `results/image_shift/curves.png`.
Все относительные пути отсчитываются от текущей рабочей директории.

JSON содержит конфигурацию и историю каждой модели: обучающие cross-entropy
и штраф, тестовую cross-entropy, accuracy на исходных и сдвинутых изображениях
(доли от 0 до 1), `invariance_mae` — среднее абсолютное отклонение логитов.
Тестовые метрики включают эпоху 0. Файл обновляется после каждого веса штрафа.
Отдельный скрипт строит по JSON графики двух accuracy и отклонения логитов.

Пример изменения параметров:

```bash
python experiments/image_shift/experiment.py --device cpu --max-shift 1 --weights 0 0.1 1 --seed 1 --output results/image_shift/seed1.json
python experiments/image_shift/plot_results.py results/image_shift/seed1.json --output results/image_shift/seed1.png
```

Гипотеза: регуляризация уменьшает чувствительность к сдвигам и улучшает
accuracy на сдвинутых данных. Большой штраф может ухудшать классификацию,
поэтому оценивайте отклонение логитов вместе с accuracy. Для проверки
устойчивости повторяйте эксперимент с другими `--seed`.
