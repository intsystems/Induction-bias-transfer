# Априор на изменения скрытых орбит студента

## Гипотеза

Удерживать инвариантность при адаптации к новым классам помогает
априор, точность которого зависит одновременно от устойчивости
скрытого направления учителя и от того, как изменение веса студента
отзывается на орбитах его собственных признаков. В первом
[эксперименте](../orbit_spectral_prior/) штраф зависел только от
устойчивости направления учителя, а инициализация видела только
чистые входы.

## Метод

На отложенных исходных изображениях MNIST вычисляем обобщённый
спектр пары ковариаций из первого эксперимента, предварительно
отбрасывая компоненты с межобъектной дисперсией менее 0,1% от
максимума. Нижняя треть оставшегося спектра определяет устойчивые
координаты учителя. Для этих координат CNN задаёт общую для орбиты
цель, среднее скрытое состояние по пяти исходным видам. Для
оставшихся координат цель зависит от вида. Студент MLP учится
предсказывать оба вида целей.

Замораживаем первый слой студента после переноса. В отложенном
исходном наборе измеряем ковариацию C отклонений признаков этого
слоя от центра орбиты. Точность априора на изменения матрицы
адаптера относительно перенесённого центра задаём произведением
Кронекера: по строкам больший вес у устойчивых координат учителя,
по столбцам используем C с единичным средним собственным значением
и положительной изотропной добавкой. Штраф ограничивает изменения
веса, которые увеличивают разброс устойчивых координат по орбите.
При адаптации доступны только чистые целевые изображения.

Спектральная оценка связана с
[Slow Feature Analysis](https://direct.mit.edu/neco/article/14/4/715/6630).
[Информативные априоры в переносе](https://arxiv.org/abs/2205.10279)
оценивают ковариацию по исходным весам. Здесь точность выводится
из отклика студента на преобразования. Изотропный контроль
мотивирован результатами
[сравнения априоров](https://arxiv.org/abs/2405.15583).

## Протокол

- Основной контраст: точность при четырёх диагональных сдвигах
  на 4 пикселя при 10 метках на класс, эпоха 50, априор против
  случайного ортогонального поворота C с тем же спектром.
- Изотропный априор контролирует эффект общего штрафа. Обратные
  веса устойчивых координат контролируют связь с учителем.
- Инициализация с общими целями сравнивается с совпадающими по
  бюджету обучением на чистых примерах и переносом зависящих от
  вида активаций. У каждого переноса заморожен один и тот же слой.
  Студент с нуля обучает все слои.
- Десять парных seed, пять на каждое из двух направлений переноса
  между классами 0–4 и 5–9. Второй бюджет — 40 меток на класс.
  Заливка показывает стандартное отклонение по seed.
