# Восстановление перестановки классов при переносе отражательной симметрии

## Гипотеза

Чётные и нечётные признаки учителя позволяют восстановить
действие отражения на метки многоклассовой целевой задачи
по малой выборке чистых примеров. Учитель передаёт студенту
геометрию скрытого пространства, а вероятностная модель
учит, какие классы остаются на месте и какие меняются парами.

## Метод

Используем [перенос отражательных признаков](../reflection_evidence/)
на [GTSRB](https://benchmark.ini.rub.de/gtsrb_dataset.html).
Истинное действие на целевые классы скрыто во время обучения.
Модельное предположение состоит в том, что действие является
инволюцией. На множестве классов оно состоит из неподвижных
точек и непересекающихся транспозиций.

Пусть матрицы C₊ и C₋ описывают гауссовские маргинальные
ковариации на размеченных целевых примерах. Они получены из
чётных и нечётных признаков студента соответственно, с общей
добавкой наблюдательного шума и малой примесью второй компоненты.
Для пары столбцов закодированных меток yᵢ, yⱼ транспозиция
переносит симметричную сумму в чётную часть, а нормированную
разность — в нечётную. Её логарифм фактора Байеса относительно
двух неподвижных классов равен

    −½ log(|C₋| / |C₊|) − ¼ (yᵢ − yⱼ)ᵀ (C₋⁻¹ − C₊⁻¹) (yᵢ − yⱼ).

При независимом до нормировки весе каждого ребра совместное
правдоподобие инволюции аддитивно по её транспозициям. Точный
постериор — распределение по взвешенным паросочетаниям.
Динамическое программирование по подмножествам даёт MAP
перестановку и маргинальную матрицу вероятностей. Прогноз
линеен по перестановке и берёт её апостериорное среднее.
Расчёт экспоненциальный по числу классов и здесь ограничен
задачами с 8 или 12 классами.

[Поиск точных инвариантностей](https://proceedings.mlr.press/v336/soleymani26a.html)
и [Equivariance by Contrast](https://proceedings.neurips.cc/paper_files/paper/2025/hash/67c689bf48fb4bb3e3abbbe92d217152-Abstract-Conference.html)
рассматривают восстановление симметрии данных и признаков.
Здесь структура переносится через учителя, а неизвестным
параметром является целевое действие на классы.
[Обобщение инвариантности по маргинальному правдоподобию](https://arxiv.org/abs/2202.10638v3)
мотивирует оценку действия в пространстве меток.

## Протокол

- 8 seed, по 8 парных выборок поддержки, бюджеты 1, 2, 4, 5
  независимых треков на класс. Учитель и студент одинаковы
  для всех голов внутри seed.
- Основной сценарий включает 12 классов, из них 8 классов
  меняются четырьмя парами. Основные контрасты при четырёх
  метках на класс — сбалансированная точность отражённого
  теста относительно случайного базиса и доля правильных
  соответствий MAP относительно паросочетания прототипов.
- Дополнительные сценарии содержат только неподвижные или
  только попарно изменяющиеся классы. Сравниваем с изотропной
  моделью, полной инвариантностью, независимыми по классам
  соответствиями, методом прототипов и известной перестановкой.
  Семантическая перестановка используется для тестовых меток
  и оракульного контроля.

```bash
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python experiments/reflection_label_matching/experiment.py --device cuda
~/venv/bin/python experiments/reflection_label_matching/plot_results.py
```

## Результаты исходного правдоподобия

RTX 3070 Laptop GPU, 8 seed, 204,7 с. Смешанный сценарий,
четыре трека на класс. Точности в процентах.

| Метод | Чистые | Отражённые | Восстановление классов |
| --- | ---: | ---: | ---: |
| Изотропный | 33,62 | 26,43 | — |
| Все классы неподвижны | 31,36 | 24,39 | 33,33 |
| Независимые соответствия | 35,01 | 27,29 | 16,41 |
| Паросочетание прототипов | 32,63 | 25,59 | 33,33 |
| Случайный базис | 33,84 | 26,89 | 21,75 |
| Точный постериор | 35,12 | 27,58 | 15,89 |
| Известная перестановка | 36,21 | 31,55 | 100,00 |

Точный постериор опередил случайный базис на отражённом
тесте на 0,69 п.п. [0,16; 1,25], но уступил прототипам
по восстановлению классов на 17,45 п.п. [−23,70; −10,94].
Интервалы получены парным bootstrap по восьми seed.
MAP в смешанном сценарии закрепляла ноль неподвижных
классов при четырёх истинных. Точность восстановления
всей перестановки составила 0%.

В задаче, где все классы меняются, восстановление
соответствий дало 40,63% против 2,34% у случайного
базиса. Полная перестановка верна в 18,75% эпизодов.
При всех неподвижных классах модель ошибочно перемещала
в среднем 7,47 класса из восьми. Эти результаты
показывают смещение исходной оценки в пользу
транспозиций, особенно при смешанной семантике классов.

Численную реализацию проверили полным перебором 76
инволюций для шести классов. Результаты совпали для
факторов Байеса, маргинальных вероятностей и MAP.

## Протокол калибровки

Исходная оценка содержит общий для каждого ребра
полуразностный логарифм детерминантов, плюс член,
зависящий от конкретной пары меток. Проверяем две
калибровки при прежних признаках студента и том же
распределении по паросочетаниям.

- Равный объём. Масштабируем C₊ и C₋ до равных
  детерминантов, одновременно масштабируя кросс-ковариации.
  Условные прогнозы сохраняются, выбор перестановки зависит
  от формы ковариаций.
- Центрирование относительно нулевой модели. Из оценки
  ребра вычитаем её ожидаемое значение при равномерной
  перестановке меток примеров с сохранением баланса.
  Для контраста d = yᵢ − yⱼ и A = C₋⁻¹ − C₊⁻¹
  математическое ожидание dᵀAd равно 2n tr(HA)/(N−1),
  где n — число меток на класс, N — размер поддержки,
  H — проектор на подпространство нулевого среднего.
  Результат используется как калиброванный вес ребра.

Дополнительно оцениваем попарное соответствие по
кросс-проверке прототипов. В каждом блоке обучения
откладываем один трек каждого класса, оцениваем
предиктивные расстояния при общей диагональной
дисперсии и по отложенным входам сравниваем соответствия.
Один вариант виртуально отражает признаки по оценённым
чётности и нечётности. Второй использует реальные
неразмеченные отражённые виды тех же треков. Второй
вариант получает дополнительные входы от преобразования.
Оба сохраняют число размеченных примеров и доступны
при двух и более метках на класс.

Основное сравнение калибровки — доля правильных
соответствий при четырёх метках в смешанной задаче.
На задаче с полностью неподвижными классами проверяем
частоту ложных транспозиций. Метод без калибровки
запускается в том же прогоне.

```bash
dir=experiments/reflection_label_matching
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/experiment.py" --device cuda --calibrate-evidence \
  --shots 2 4 5 --output "$dir/results/calibrated/metrics.json"
~/venv/bin/python "$dir/plot_results.py" --metrics "$dir/results/calibrated/metrics.json" \
  --output "$dir/results/calibrated/curves.png"
```

четырёх метках на класс, в процентах. Все методы в таблице
используют одни и те же экземпляры учителя и студента

| Оценка | Смешанные | Все неподвижные | Все меняются |

| Центрирование по нулевой модели | 37,89 | 82,03 | 22,27 |

В смешанном сценарии общий член логарифма правдоподобия
в пользу каждой транспозиции достигал 11,60 в среднем.
Равный объём сократил число перемещённых классов с 12,00
до 8,69 при восьми истинных. Нулевое центрирование дало
2,84 перемещённых класса и улучшило долю правильных
соответствий на 17,32 п.п. [15,10; 19,53].
Обе калибровки снизили точность в сценарии, где все
классы меняются. Нулевое центрирование улучшило
смешанное восстановление главным образом за счёт
отбрасывания неверных транспозиций.

Кросс-проверка виртуальных видов опередила исходный
метод на 21,62 п.п. [14,97; 28,65] по соответствиям,
на отражённом тесте дала 29,39% против 28,72%.
Наблюдаемые виды дали 29,47% на отражённом тесте.
Полное соответствие восстановлено только у варианта
с наблюдаемыми видами в 1,56% смешанных эпизодов.
Интервалы получены парным bootstrap по восьми seed.

## Проверка оператора в координатах студента

Кросс-проверка с виртуальным отражением изначально использует
знаки направлений учителя. У студента отражательную структуру
можно измерить непосредственно на отложенных исходных парах.
Подгоняем симметричную ортогональную инволюцию с числом
отрицательных собственных значений, заданным учителем.
У критерия Прокруста есть спектральное решение. Собственные
векторы берём из симметричной взаимной ковариации видов с
добавкой 0,1 к масштабу согласования с оператором учителя.

В одном варианте кросс-проверяем отражение признаков от
глобального нуля. В другом сначала вычитаем среднее между
классами, затем применяем инволюцию и возвращаем среднее.
Это среднее оценивается только по сохранённым трекам
внутри каждого блока кросс-проверки. При сбалансированной
поддержке и замкнутом множестве классов оценка учитывает
общее смещение целевых признаков относительно исходных
координат. Прогнозы условных голов и алгоритм
паросочетаний сохраняются.

Основной контраст при четырёх метках в смешанном наборе —
точность соответствий при совместной коррекции оператора
и среднего относительно исходной кросс-проверки виртуальных
видов. Раздельные варианты проверяют обе составляющие.
Добавляем сценарий `fixed_heavy` с восемью неподвижными
и четырьмя меняющимися классами. Seed 21–36 независимо
от прежней проверки. Ошибка преобразования в латенте
измеряется на исходной выборке для подгонки и отдельно
на целевых тестовых парах в качестве диагностики.

```bash
dir=experiments/reflection_label_matching
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/experiment.py" --device cuda --calibrate-operator \
  --seeds $(seq 21 36) --shots 2 4 5 --output "$dir/results/operator/metrics.json"
~/venv/bin/python "$dir/plot_results.py" --metrics "$dir/results/operator/metrics.json" \
  --output "$dir/results/operator/curves.png"
```
