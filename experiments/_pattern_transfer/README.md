# Общие данные и модели

Этот каталог содержит общие функции двух самостоятельных экспериментов:
[`learned_augmentation`](../learned_augmentation/README.md) и
[`hidden_prior`](../hidden_prior/README.md). `common.py` содержит генератор,
модели и обучение, `plotting.py` — общие функции построения графиков.

Генератор перенесён из `assets/conv_data_v2.ipynb` без выполнения ноутбука:

- выбирается случайный бинарный шаблон длины 12;
- генерируются случайные последовательности длины 24; метка означает наличие
  шаблона в любой позиции, входы кодируются числами `-1` и `+1`;
- train и test генерируются отдельно; в отрицательные примеры вставляется шаблон,
  пока положительных не станет как минимум половина в каждой выборке;
- для тестовых пар выбирается один из четырёх сдвигов на один элемент,
  сохраняющий истинную метку: влево/вправо с заполнением `-1`/`+1`.

Сохраняется ограничение размеров из ноутбука. Python `random` заменяет NumPy:
seed воспроизводит новые выборки, но не даёт побитового совпадения с ноутбуком.
Как и в ноутбуке, повторяющиеся последовательности не удаляются. `gold_params`
и метаданные направления сдвига не используются. Учителя обучаются по меткам.
Шаблоны исходной и целевых задач принудительно различаются.

Учителя: CNN с Conv1d, ReLU, max pooling и линейной головой; MLP с полносвязным
слоем, ReLU и линейной головой. CNN задаёт смещение к общим локальным признакам,
MLP служит контролем. Студент всегда MLP.

По умолчанию используются три целевых шаблона, 512 train/test-примеров на задачу
и обучающие подвыборки размеров `32`, `128`, `512`. Подвыборки — префиксы большой
выборки, без отдельной балансировки. В пределах целевой задачи методы получают
одинаковые данные и порядок батчей. Тестовые пары сдвигов фиксированы.
