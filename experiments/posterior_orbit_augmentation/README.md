# Генератор отражённых видов с апостериорным переносом меток

## Гипотеза

Если одно и то же преобразование сохраняет метки одних задач
и меняет метки других, генератору нужно переносить не только
изображения, но и метки. Проверяем, помогает ли усреднение
двух действий на метку по их правдоподобию на малой целевой выборке.
Отдельный вопрос — добавляет ли пользу непрерывный условный
генератор при этом же способе переноса меток.

## Метод

Используем [официальный GTSRB](https://benchmark.ini.rub.de/gtsrb_dataset.html)
и те же восемь задач, что в
[эксперименте с априором](../reflection_evidence/).
Учитель CNN с отражательным смещением обучается на других
классах. Замороженный MLP-энкодер воспроизводит его чётные
и нечётные координаты.

CNN-генератор по отражённому исходному изображению предсказывает
параметры нормального распределения непрерывной позы.
Сэмпл после ограничивающего преобразования задаёт поворот до 12°
и два сдвига до трёх пикселей. Генератор обучается сохранять
активации учителя при возмущении отражённого изображения.
Штраф KL к стандартному нормальному распределению оставляет
генератору ненулевой диапазон поз и задаёт контроль с базовой
позой при одинаковом исходном шуме.

По чистой целевой выборке сравниваем чётную и нечётную модели
через маргинальное правдоподобие гауссовских априоров.
Пусть p — апостериорная вероятность сохранения метки.
Генерируем отражённые виды с целевой мишенью (2p − 1)y
для исходной метки y ∈ {−1, 1}. Эта мишень равна ожидаемой
метке при двух действиях и квадратичной функции потерь.
Общий вес всех синтетических видов каждого примера равен
весу одного исходного. Голова студента обучается на чистых
и сгенерированных примерах. Инференс выполняется студентом
по одному изображению.

[Learning to Transform](https://arxiv.org/abs/2309.16672v3)
мотивирует генерацию поз, зависящую от экземпляра.
Здесь генератор переносится между классами, а действие
на целевые метки оценивается по целевой выборке поддержки.

## Протокол

- 8 seed, 10 выборок поддержки на задачу, 1/2/4/5 независимых
  физических треков на класс. Те же выборки используются всеми
  методами. Тестовый протокол оценивает чистые и отражённые
  изображения с обновлёнными по смыслу метками.
- Основной контраст при четырёх метках — точность на отражённых
  знаках со сменой класса у апостериорно взвешенных и неизменённых
  меток при одних и тех же сгенерированных входах. Отдельно
  сравниваем со смесью априоров без аугментаций, базовым
  генератором поз и точным отражением с теми же мягкими метками.
  Перестановка поз внутри мини-пакетов одного класса сохраняет
  их распределение и разрывает зависимость от изображения.
- Контроли: голова на чистых данных, фиксированная смена метки
  и семантически правильная метка, доступная оракулу.
  Разброс на кривых — стандартное отклонение средних по seed.

```bash
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python experiments/posterior_orbit_augmentation/experiment.py --device cuda
~/venv/bin/python experiments/posterior_orbit_augmentation/plot_results.py
```

## Результаты

RTX 3070 Laptop GPU, 8 seed, 112,8 с. Сбалансированная
точность при четырёх метках на класс, в процентах.

| Метод | Чистые, класс сохраняется | Отражённые, класс сохраняется | Чистые, класс меняется | Отражённые, класс меняется |
| --- | ---: | ---: | ---: | ---: |
| Без аугментации | 67,52 | 66,84 | 75,12 | 67,27 |
| Адаптивный априор без аугментации | 67,26 | 66,71 | 79,39 | 72,13 |
| Генератор, метка сохранена | 68,73 | 68,67 | 55,55 | 47,38 |
| Генератор, метка изменена | 53,92 | 51,55 | 81,00 | 81,26 |
| Генератор, мягкая метка | 67,18 | 67,03 | 79,26 | 72,08 |
| Базовая поза, мягкая метка | 67,19 | 67,14 | 78,86 | 71,49 |
| Переставленные позы, мягкая метка | 67,43 | 67,18 | 79,43 | 72,07 |
| Точное отражение, мягкая метка | 67,41 | 67,17 | 79,40 | 72,40 |
| Генератор, метка оракула | 68,73 | 68,67 | 81,00 | 81,26 |

Основной контраст дал +24,70 п.п. [20,68; 28,38] против
неизменённых меток в задачах со сменой класса. Отличие от
адаптивного априора без аугментации составило −0,05 п.п.
[−0,83; 0,60], от переставленных поз +0,01 п.п. [−0,29; 0,32],
от точного отражения −0,32 п.п. [−0,74; 0,10]. Интервалы
получены парным bootstrap по seed с 10 000 повторов.

Средняя вероятность сохранения метки составила 0,716
для задач с сохранением класса и 0,299 для задач со сменой.
По сравнению с базовым распределением выученный генератор
уменьшил амплитуды и немного улучшил результат на знаках
со сменой класса. При той же маргинали поз связь позы
с конкретным изображением измеримого вклада не дала.
В этом протоколе основной эффект принадлежит переносу
действия на метки. Правило, известное оракулу, даёт
ещё 9,18 п.п. на задачах со сменой класса.

## Условная голова для каждого действия на метки

Проверяем, помогает ли генерировать примеры внутри двух
моделей действия, а затем усреднять прогнозы. У каждой
модели своя априорная ковариация и своё действие на метку.
Одна голова использует преимущественно чётные координаты
и неизменённые метки. Вторая использует преимущественно
нечётные и смену знака метки. Вероятности двух моделей
оцениваются только по чистой поддержке, до генерации.
Дополнительные виды обновляют параметры каждой головы.

Оценка с нулевым центрированием сравнивает квадратичные
формы относительно их средних при случайной перестановке
сбалансированных меток. Это устраняет общий сдвиг в пользу
одной ковариации при отсутствии связи признаков и меток.
Вариант с изотропной головой сохраняет мягкие метки и
уменьшает общий вес сгенерированных видов пропорционально
квадрату уверенности `(2p − 1)²`.

Повтор на независимых seed 43–58. Основной контраст
при четырёх метках в задачах со сменой класса сравнивает
центрированную условную модель с генерацией и ту же
модель без генерации. Точное отражение при том же
правиле меток служит контролем для генератора поз.
Записываем результаты также для задач с сохранением
класса, исходного мягкого правила и правила оракула.

```bash
dir=experiments/posterior_orbit_augmentation
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/experiment.py" --device cuda --mode-conditioned \
  --seeds $(seq 43 58) --output "$dir/results/conditional/metrics.json"
~/venv/bin/python "$dir/plot_results.py" --metrics "$dir/results/conditional/metrics.json" \
  --output "$dir/results/conditional/curves.png"
```

### Результаты условных голов

RTX 3070 Laptop GPU, 16 новых seed, 300,2 с.
Сбалансированная точность на отражённых знаках при
четырёх метках на класс, в процентах.

| Метод | Класс сохраняется | Класс меняется |
| --- | ---: | ---: |
| Без аугментации | 69,45 | 68,89 |
| Смесь априоров без аугментации | 69,36 | 74,91 |
| Генерация с мягкой меткой | 69,81 | 75,50 |
| Условная голова, центрирование, без генерации | 68,33 | 77,80 |
| Условная голова, центрирование, генерация | 67,38 | 78,77 |
| Условная голова, центрирование, точное отражение | 67,60 | 78,76 |
| Генерация с меткой оракула | 70,96 | 83,13 |

В основном контрасте генерация повысила точность
условной головы на 0,97 п.п. [0,39; 1,54] в задачах
со сменой класса. В задачах с сохранением класса
разность составила −0,95 п.п. [−1,29; −0,60].
Сравнение с точным отражением даёт +0,01 п.п.
[−0,40; 0,41] в задачах со сменой класса.
Интервалы получены парным bootstrap по 16 seed.

Центрирование уменьшило среднюю вероятность
сохранения метки с 0,280 до 0,185 в задачах со
сменой класса и с 0,771 до 0,648 в задачах
без смены. Изменение помогает одной группе ценой
другой. Генератор и точное отражение при одинаковой
условной модели практически эквивалентны на
отражённом тесте.
