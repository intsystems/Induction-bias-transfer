# Перенос спектра устойчивости скрытых признаков

## Гипотеза

При переносе между непересекающимися классами априор на веса студента
лучше сохраняет устойчивость к сдвигу, если его точность выше в скрытых
направлениях, устойчивых у учителя. Проверяем вклад геометрии априора
при одном и том же центре, инициализации, числе меток и параметров.

## Метод

Учитель CNN обучается на цифрах MNIST 0–4. Для отложенных изображений
исходных классов вычисляем признаки предпоследнего слоя в пяти точках
орбиты: исходное изображение и сдвиги на два пикселя по четырём
направлениям. По признакам оцениваем внутриорбитальный разброс W и
ковариацию центров орбит B. Направления упорядочиваем по обобщённым
собственным значениям пары (W, B + εI). Малое собственное значение
соответствует малому разбросу по орбите при вариативности между примерами.
Семейство сдвигов задано заранее, устойчивые направления оцениваются
по активациям учителя.

Студент MLP воспроизводит координаты чистых исходных примеров в этом
базисе. При адаптации к цифрам 5–9 обучаем все параметры. MAP-подобный
квадратичный штраф действует на строки последней матрицы энкодера:
точность линейно падает с 1,6 до 0,4 по рангу собственного значения.
Голова классификатора инициализируется случайно. Все методы используют
чистые целевые входы и не обращаются к учителю при адаптации или тесте.

Ближайший аналог для переноса геометрии скрытых орбит — [Orbit Transfer](https://proceedings.mlr.press/v151/nix22a.html).
Здесь орбитальные статистики задают покоординатную точность априора
в параметрах и сохраняются после удаления учителя. [LaLiGAN](https://arxiv.org/abs/2310.00105v3)
мотивирует поиск структуры в латентном пространстве, а [McCoy и Griffiths](https://www.nature.com/articles/s41467-025-59957-y)
и [MAML](https://arxiv.org/abs/1703.03400v3) мотивируют перенос через начальные параметры.

## Протокол

- Основное сравнение на 40-й эпохе при 10 метках на класс: средняя
  точность на четырёх диагональных сдвигах на четыре пикселя для
  орбитального и изотропного априоров. Обратный порядок точностей
  проверяет специфичность спектра.
- Дополнительные сравнения: 40 меток на класс, исходные изображения,
  доля примеров с правильным ответом на всех сдвигах, несогласие с
  ответом на чистом изображении, инициализация без штрафа и обучение с нуля.
- Изображения дополнены четырьмя нулевыми пикселями с каждой стороны.
  Сдвиги на тесте сохраняют пиксели исходного изображения. Методы
  сравниваются попарно на одинаковых данных и seed. Заливка на
  графиках показывает стандартное отклонение между seed.
