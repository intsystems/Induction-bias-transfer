# Совместный перенос двух коммутирующих отражений

## Гипотеза

Модель, которая восстанавливает действие двух генераторов
на новые классы совместно, точнее переносит неизвестную
композицию, чем отдельные апостериорные оценки генераторов.
Проверяем вклад коммутирования при одинаковой геометрии
признаков и одинаковом числе меток.

## Метод

В синтетическом эксперименте аналитический учитель выдаёт
латентные состояния с четырьмя знаковыми представлениями
группы C₂ × C₂. Наблюдается произвольно повёрнутый базис.
Ортогональная задача Прокруста оценивает два действия
раздельно по парам исходных состояний. Совместный базис
оценивается спектрально по взвешенной сумме симметричных
частей двух оценок. Студент восстанавливает признаки
учителя из нелинейно смешанных входов с помощью
случайных нелинейных признаков и ridge-адаптера.

По чистым примерам шести новых классов оцениваем неизвестные
инволюции P и Q на метках. Для коммутирующей пары проектор
каждого характера имеет вид (I ± P)(I ± Q)/4. Предполагаем
гауссовскую модель для столбцов целевых меток в каждом
пространстве характера, с априором головы, заданным
соответствующими активациями учителя. Маргинальное
правдоподобие вычисляется по следам произведений этих
проекторов на условные квадратичные формы. Перебираем
коммутирующие пары и усредняем прогнозы по их вероятности.

Контроль оценивает по одному паросочетанию на генератор,
объединяет средние матрицы в симметризованные совместные
проекторы и использует те же четыре условные модели головы.
Сравниваем также с изотропным априором и истинными
перестановками классов. Последние доступны только оракулу
и анализу результатов.

## Протокол

- 16 независимых seed, по 12 целевых задач на seed.
  Бюджеты 2, 4 и 8 меток на класс. Проверяются точные
  исходные пары и 55% неверных соответствий.
- Основной контраст при четырёх метках — точность
  восстановления действия композиции из совместной и
  независимых MAP-оценок при 55% неверных пар. Дополнительно
  измеряем точность классификации на композиции, совпадение
  обоих генераторов и долю классов, на которых независимо
  оценённые генераторы не коммутируют.
- Переход к другому положению в тесте меняет общий вектор
  помех и обновляет метки через композицию. Синтетическая
  постановка изолирует механизм и оставляет проверку более
  сложных групп на реальных данных открытой.

```bash
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python experiments/commuting_label_actions/experiment.py
~/venv/bin/python experiments/commuting_label_actions/plot_results.py
```

## Результаты

16 seed, 192 задачи на условие, 5,4 с в серверном
окружении NumPy. Всего 1216 допустимых пар
коммутирующих инволюций из 76 инволюций на шести классах.

Четыре метки на класс и 55% неверных пар, в процентах.

| Метод | Точность на композиции | Восстановление генераторов | Восстановление композиции | Оба генератора целиком |
| --- | ---: | ---: | ---: | ---: |
| Изотропный | 61,98 | — | — | — |
| Независимый | 76,83 | 89,15 | 84,11 | 57,81 |
| Совместный | 77,28 | 88,19 | 91,15 | 63,54 |
| Оракул | 80,33 | 100,00 | 100,00 | 100,00 |

В основном контрасте совместный метод дал +7,03 п.п.
[4,17; 9,90] по восстановлению композиции. При
точных парах эффект +5,73 п.п. [3,21; 8,68].
Интервалы получены парным bootstrap по 16 seed.
Выигрыш в классификации составил 0,45 п.п.
[0,09; 0,85] при 55% неверных пар. Независимые
MAP-действия не коммутировали на 13,37% классов.
Совместная модель исключает эти нарушения по построению.

чем у независимого контроля. Наблюдаемое преимущество
сосредоточено в восстановлении композиции.
