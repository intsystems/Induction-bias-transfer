# Калибровка отражательного априора по отклику студента

## Гипотеза

После переноса скрытых состояний чётные координаты учителя
могут меняться в реализации студента. Если априор на
коэффициенты головы учитывает эти отклонения, то он лучше
перенесёт отражательную устойчивость на новые классы с
одним проходом модели.

## Метод

CNN обучается на четырёх исходных классах
[CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html)
(самолёт, птица, лягушка и корабль). Студент MLP
воспроизводит чётные и нечётные координаты учителя
по [протоколу переноса](../reflection_evidence/).
Шесть оставшихся классов используются только для
адаптации головы и теста. Горизонтальное отражение
сохраняет их категорию.

На отложенных изображениях исходных классов измеряем
ковариацию C полуразностей скрытых состояний студента
для изображения и отражения. Нормируем C до среднего
собственного значения 1. Ковариация априора, полученная
из студента, пропорциональна (I + 4C)⁻¹. Априор учителя
пропорционален D², где D диагональна и уменьшает
стандартное отклонение нечётных координат. Совместный
априор пропорционален D(I + 4C)⁻¹D. Это мягко ограничивает
коэффициенты, ведущие к фактическим ошибкам отражения
в скрытых состояниях студента. Все априоры имеют одинаковый
след. Голова подбирается через гауссовскую регрессию
на центрированное кодирование классов.

Контроль заменяет C случайно повёрнутой матрицей с тем же
спектром при той же D. Ещё один контроль напрямую усредняет
признаки двух видов при обучении и проверке, а затем
использует изотропную голову. Представление у него
инвариантно по построению и требует двух проходов MLP.

## Протокол

- 8 seed, по 8 вложенных выборок поддержки на seed,
  бюджеты 5, 20 и 60 меток на класс. Официальный тест
  использует 600 примеров каждого из шести классов
  на seed. Все методы сравниваются на тех же примерах.
- Основной контраст при 20 метках — доля примеров,
  правильно классифицированных в обоих видах, у
  совместного априора и априора только по учителю.
  Контроль со случайным поворотом проверяет вклад
  выученной студенческой геометрии.
- На тесте аналитики учитывают чистые и отражённые виды.
  Все модели, кроме явно двухвидового контроля, вычисляют
  каждый вид отдельно за один проход. Заливка показывает
  стандартное отклонение по seed.

```bash
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python experiments/student_symmetry_calibration/experiment.py --device cuda
~/venv/bin/python experiments/student_symmetry_calibration/plot_results.py
```

## Результаты

RTX 3070 Laptop GPU, восемь seed, 66,6 с. Точность исходного
учителя на отложенной выборке четырёх исходных классов составляла 68,76%
на исходной задаче. Средняя квадратичная ошибка отражения
в перенесённых чётных координатах студента — 0,0180.

Точность при 20 метках на класс, в процентах.

| Априор | Чистые | Отражённые | Оба вида |
| --- | ---: | ---: | ---: |
| Изотропный | 25,96 | 25,94 | 16,42 |
| Учитель | 26,24 | 26,31 | 18,06 |
| Ковариация студента | 26,13 | 26,13 | 22,39 |
| Совместный | 26,38 | 26,47 | 18,03 |
| Совместный со случайным поворотом | 26,24 | 26,29 | 18,05 |
| Два вида | 27,75 | 27,75 | 27,75 |

Основной контраст совместного и учительского априора
по точности сразу на двух видах составил −0,03 п.п.
[−0,70; 0,70]. Совместный априор уступил ковариации
студента без учительской маски на 4,36 п.п. [−5,42; −3,21].
Интервалы получены парным bootstrap по восьми seed.

Ковариация студента дала +5,97 п.п. к изотропному
априору по точности сразу на двух видах при изменении
точности конкретного вида менее чем на 0,2 п.п.
Согласие классификаций выросло с 56,30% до 82,52%.
Двухвидовой контроль точнее всех. Результат показывает
улучшение согласованности одного прохода при
априоре, рассчитанном по реакции студента. Прямая
маска направлений учителя ослабила этот эффект.
Абсолютная точность на новых классах остаётся низкой.
