# Калибровка отражательного априора по отклику студента

## Гипотеза

После переноса скрытых состояний чётные координаты учителя
могут меняться в реализации студента. Если априор на
коэффициенты головы учитывает эти отклонения, то он лучше
перенесёт отражательную устойчивость на новые классы с
одним проходом модели.

## Метод

CNN обучается на четырёх исходных классах
[CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html)
(самолёт, птица, лягушка и корабль). Студент MLP
воспроизводит чётные и нечётные координаты учителя
по [протоколу переноса](../reflection_evidence/).
Шесть оставшихся классов используются только для
адаптации головы и теста. Горизонтальное отражение
сохраняет их категорию.

На отложенных изображениях исходных классов измеряем
ковариацию C полуразностей скрытых состояний студента
для изображения и отражения. Нормируем C до среднего
собственного значения 1. Ковариация априора, полученная
из студента, пропорциональна (I + 4C)⁻¹. Априор учителя
пропорционален D², где D диагональна и уменьшает
стандартное отклонение нечётных координат. Совместный
априор пропорционален D(I + 4C)⁻¹D. Это мягко ограничивает
коэффициенты, ведущие к фактическим ошибкам отражения
в скрытых состояниях студента. Все априоры имеют одинаковый
след. Голова подбирается через гауссовскую регрессию
на центрированное кодирование классов.

Контроль заменяет C случайно повёрнутой матрицей с тем же
спектром при той же D. Ещё один контроль напрямую усредняет
признаки двух видов при обучении и проверке, а затем
использует изотропную голову. Представление у него
инвариантно по построению и требует двух проходов MLP.

## Протокол

- 8 seed, по 8 вложенных выборок поддержки на seed,
  бюджеты 5, 20 и 60 меток на класс. Официальный тест
  использует 600 примеров каждого из шести классов
  на seed. Все методы сравниваются на тех же примерах.
- Основной контраст при 20 метках — доля примеров,
  правильно классифицированных в обоих видах, у
  совместного априора и априора только по учителю.
  Контроль со случайным поворотом проверяет вклад
  выученной студенческой геометрии.
- На тесте аналитики учитывают чистые и отражённые виды.
  Все модели, кроме явно двухвидового контроля, вычисляют
  каждый вид отдельно за один проход. Заливка показывает
  стандартное отклонение по seed.

```bash
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python experiments/student_symmetry_calibration/experiment.py --device cuda
~/venv/bin/python experiments/student_symmetry_calibration/plot_results.py
```

## Проверка ориентации и силы ковариации

В исходном замере ковариация самого студента улучшила
согласованность двух видов. Проверяем, связан ли эффект
со специфическими направлениями орбиты или с анизотропным
сжатием какого-либо базиса.

Для каждого множителя `λ ∈ {0,5; 2; 4; 8; 32}` сравниваем
`(I + λC)⁻¹` с его ортогональным поворотом. Пара имеет
одинаковый спектр, след и центральные параметры. Один
и тот же поворот используется на всём диапазоне λ
внутри seed. Дополнительный контроль использует
ковариацию между центрами орбит при λ = 4.

Новые seed 31–42. Основной контраст фиксирован при λ = 4
и 20 метках на класс: разность долей правильных ответов
на обоих видах. Точность чистых изображений и согласие
ответов измеряются отдельно. Варьирование λ проверяет
устойчивость вывода, а график показывает парную разность
для каждого бюджета. Выбор λ по данным целевого теста
не используется.

## Априор с инвариантностью к линейной замене координат

Обычный априор использует единичную матрицу как фоновую
метрику параметров. Его вывод может измениться при
эквивалентном линейном изменении скрытых координат
студента. Заменяем фоновую метрику полной ковариацией T
исходных признаков. Для ковариации W полуразностей
отражённых видов предлагаем априор, пропорциональный
`(T + εM + λW)⁻¹`. M — опорная метрика, единичная
в исходном базисе студента. Регуляризация ε составляет
10⁻⁴ средней дисперсии координат в этом базисе. Первый
запуск остановился на вырожденной T, поэтому переносим
вместе с данными и метрику M. Нормируем априор так,
чтобы след (T + εM)Σ был равен единице.

При обратимой замене координат z → zA ковариации
и опорная метрика преобразуются как `AᵀTA`,
`AᵀWA` и `AᵀMA`. Ковариация весов меняется
обратным сопряжением, а ядро прогноза остаётся тем же.
Вычисляем априор в белом базисе T + εM.
Случайный поворот орбитального члена в этом базисе
сохраняет обобщённые собственные значения пары W и T + εM.

На новых seed 61–72 сравниваем исходные координаты
с неортогональной линейной заменой
с числом обусловленности 16. Ко всем исходным и целевым
признакам применяется одна и та же обратимая матрица,
а выборки поддержки совпадают. Основной статистический
контраст в исходных координатах — орбитальный априор
против повёрнутого при 20 метках на класс. Дополнительно
проверяем относительное отклонение тестового ядра после
линейной замены и совпадение точностей.

```bash
dir=experiments/student_symmetry_calibration
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/experiment.py" --device cuda --gauge-check \
  --seeds $(seq 61 72) --output "$dir/results/coordinates/metrics.json"
~/venv/bin/python "$dir/plot_results.py" --metrics "$dir/results/coordinates/metrics.json" \
  --output "$dir/results/coordinates/curves.png"
```

## Выбор силы априора по исходной дисперсии орбит

Фиксированное λ в белом базисе оставляет допустимую
дисперсию отклика разной для разных учителей и задач.
Вместо λ задаём долю `ρ` исходной орбитальной дисперсии
изотропного априора в этом базисе. Для ковариации весов
Σ требуем `tr((T + εM)Σ) = 1` и
`tr(WΣ) ≤ ρ tr(W(T + εM)⁻¹)/d`,
где d — ширина признаков.

В белом базисе оптимизация энтропии ковариации даёт
веса, обратно пропорциональные аффинной функции
обобщённых собственных значений. После сдвига
спектра относительно минимума подбираем множитель
бисекцией, используя только исходные пары.
При недостижимом ограничении записываем фактическую
долю. Для каждого ограничения сравниваем с
поворотом той же ковариации в белом базисе.
Поворот сохраняет спектр и расчётную дисперсию
самой головы в исходной метрике.

Для проверки используем 16 новых разделений
CIFAR-10, seed 125–140. Исследуем `ρ ∈ {0,75; 0,50; 0,25}`.
Основной контраст при 20 метках на класс и ρ = 0,25 —
точность на обоих видах против случайного поворота.
Отдельно измеряем разность со стандартным
орбитальным априором и абсолютную точность каждого
вида. Все параметры определяются по исходным
скрытым состояниям, до целевой адаптации.

```bash
dir=experiments/student_symmetry_calibration
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/experiment.py" --device cuda --gauge-check --vary-classes \
  --variance-budgets 0.75 0.5 0.25 --seeds $(seq 125 140) --output "$dir/results/variance_budget/metrics.json"
~/venv/bin/python "$dir/plot_results.py" --metrics "$dir/results/variance_budget/metrics.json" \
  --output "$dir/results/variance_budget/curves.png"
```

## Сколько исходных пар нужно для оценки априора

После обучения энкодеров и определения их координат
фиксируем модели. Сравниваем априоры, посчитанные
на вложенных выборках из 32, 128, 512 и 1280 исходных
пар. Выборки сбалансированы по четырём исходным
классам. Ограничение орбитальной дисперсии составляет
25%. Для каждой выборки пересчитываем среднее,
метрику и ковариацию разностей. Поддержка целевой
задачи, тест и поворот для контроля фиксированы
внутри seed. Объём обучения самих энкодеров
остаётся одинаковым.

Берём 16 новых разделений классов, seed 141–156.
Основной контраст при 20 метках на класс —
выигрыш ориентированного априора над повёрнутым
при 32 парах и разность этого выигрыша относительно
1280 пар. Дополнительно измеряем численный ранг и
ошибку ядра при смене координат. При 32 парах ранг
ограничен 63, поскольку полная ковариация строится
из 64 центрированных состояний. Этот режим проверяет
опорную регуляризацию на реальных признаках.

```bash
dir=experiments/student_symmetry_calibration
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/experiment.py" --device cuda --gauge-check --vary-classes \
  --calibration-pairs 32 128 512 --variance-budgets 0.25 --seeds $(seq 141 156) \
```

## Устойчивость к неверным соответствиям

У уже обученного студента случайно переставляем отражения внутри вложенной
доли исходных пар. Ни одна выбранная пара не остаётся на месте, а наборы
изображений по обе стороны сохраняются. Гипотеза состоит в том, что 32
проверенные пары позволяют использовать остальные даже при ошибках
сопоставления. В чётных координатах подгоняем две модели логарифма расстояния
по проверенным и переставленным парам. Смешивающую долю оцениваем на
непроверенных парах, после чего взвешиваем внешние произведения орбитальных
разностей вероятностью правильного соответствия.

Все методы используют одну общую метрику исходных состояний, один бюджет
дисперсии 25% и одни целевые эпизоды. Сравниваем с равными весами,
32 проверенными парами, поворотом взвешенной ковариации и двумя оракулами
(известная маска ошибок и исходные пары до перестановки).
Калибровка расстояний привязана к чётному блоку учителя. Шум моделирует
случайные ошибки сопоставления уже после обучения представления.
Основной контраст при 50% ошибок и 20 метках на класс — изменение
точности сразу на двух видах относительно равного взвешивания.
Дополнительно измеряем ошибку исходной ковариации. См. близкую постановку
[шумных соответствий](https://openaccess.thecvf.com/content/CVPR2024/papers/Yang_Robust_Noisy_Correspondence_Learning_with_Equivariant_Similarity_Consistency_CVPR_2024_paper.pdf).

```bash

OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/pair_noise.py" --device cuda
~/venv/bin/python "$dir/plot_pair_noise.py" --metrics "$dir/results/pair_noise/metrics.json" \
  --output "$dir/results/pair_noise/curves.png"
```

### Восстановление взаимно однозначных соответствий

Взвешивание использует только предложенную пару. Проверяем, даёт ли
дополнительный эффект восстановление всей перестановки по тем же чётным
координатам. Сравниваем ближайшего соседа для каждой строки и глобальное
назначение с минимальной суммой логарифмов расстояний. В третьем варианте
масштабируем расстояния через общий разброс оценок на проверенных парах
и добавляем исходной диагонали логарифм априорных шансов. Долю правильных
исходных пар оцениваем прежним методом смеси. Априор студента строится
по восстановленным орбитальным разностям. Литература о восстановлении
перестановок мотивирует сравнение локального и глобального назначения.
[Обобщённая регрессия с перестановками](https://openaccess.thecvf.com/content/ICCV2021/papers/Li_Generalized_Shuffled_Linear_Regression_ICCV_2021_paper.pdf)

Измеряем два режима. В первом перестановка идёт по всей исходной
выборке. Во втором ошибки возникают только внутри исходного класса.
Классовые метки для восстановления соответствий не используются.
Основной контраст при 75% ошибок внутри класса и 20 метках на целевой
класс сравнивает назначение со штрафом за изменение исходной пары
с прежним мягким взвешиванием. Отдельно сравниваем долю верно
восстановленных пар, ошибку ковариации и поведение при чистом входе.
Взаимно однозначное назначение предполагает, что обе стороны содержат
одни и те же экземпляры. Здесь нет пропущенных или повторных видов.

```bash
dir=experiments/student_symmetry_calibration
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/pair_noise.py" --device cuda --repair \
  --fractions 0 .5 .75 .95 --output "$dir/results/pair_repair/metrics.json"
OPENBLAS_NUM_THREADS=1 ~/venv/bin/python "$dir/pair_noise.py" --device cuda --repair --within-class-noise \
  --fractions 0 .5 .75 .95 --output "$dir/results/pair_repair_within_class/metrics.json"
for result in pair_repair pair_repair_within_class; do
  ~/venv/bin/python "$dir/plot_pair_noise.py" --metrics "$dir/results/$result/metrics.json" \
    --output "$dir/results/$result/curves.png"
done
```

### Калибровка скрытой симметрии перед восстановлением пар

В предыдущей проверке глобальное назначение по чётным координатам
восстановило около трети пар. Здесь проверяем, дают ли дополнительные
сведения нечётные координаты, если сначала учесть действие отражения.
На правом виде меняем знак в нечётном блоке, заданном учителем.
Затем оцениваем небольшую аффинную поправку к этому известному действию
на 32 проверенных парах. В общей белой метрике обучаем отображение справа
налево с ridge-штрафом на отклонение линейной части от единичной матрицы.
Поправка влияет на выбор соответствий. Ковариация орбит по выбранным парам
считается из исходных признаков студента.

Сравниваем назначение по чётному блоку, калибровку чётного блока, смену
знака во всех нечётных координатах и её последующую калибровку. Контроль
подгоняет ту же аффинную поправку на переставленных проверенных парах.
Целевые эпизоды и энкодер общие для всех методов.

Основное условие — 75% перестановок внутри исходного класса и 20 меток
на целевой класс. Сравниваем точность обоих видов после калибровки
полного действия с назначением по чётному блоку. Сравнение с простой
сменой знака и с неправильными опорными парами оценивает вклад
калибровки. Это проверка на фиксированных энкодерах с известным
кандидатом на действие отражения и полностью наблюдаемыми орбитами.
Аффинная подгонка по опорным парам родственна методам совмещения разных
скрытых пространств. [Прямое совмещение скрытых пространств](https://geometryinml.cs.uni-bonn.de/assets/pdfs/laehner2023latent.pdf)

## Частично наблюдаемые пары на CIFAR-10

Проверяем, уменьшает ли отказ от сомнительных пар искажение ковариации орбит и повышает ли точность студента. Доля общих изображений в двух списках видов составляет 25, 50, 75 или 100%. Отсутствующие отражения заменяем отражениями других изображений того же исходного класса, после чего перемешиваем правый список. Сопоставление получает только признаки. Размеченные пары для оценки порога и парность примеров в целевой задаче в этот список не входят.

В признаках правого вида применяем знаковое действие учителя и калибровку на 32 известных парах. В четырёх складках кросс-валидации выбираем порог по сбалансированной точности различения истинной пары и ближайшего заведомо чужого отражения. Сравниваем обязательное назначение, отбрасывание после назначения, ближайшего соседа с тем же порогом и назначение с возможностью отказа. Последний вариант добавляет фиктивные столбцы со стоимостью, равной порогу. Частичное назначение известно из задач сопоставления визуальных признаков. Здесь проверяем его влияние на ковариацию орбит в пространстве признаков студента и через неё на априор весов классификатора. [Sarlin и соавт., 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Sarlin_SuperGlue_Learning_Feature_Matching_With_Graph_Neural_Networks_CVPR_2020_paper.html)

## Оценка ковариации орбит по непарным видам

Проверяем, может ли действие учителя снизить ошибку оценки априора при отсутствии соответствий. Пусть `P_-` — проектор на нечётные координаты, выявленные в признаках учителя, `W` — нормировка признаков студента по наблюдаемым видам, а `h` — строка признаков студента. При точном действии отражения разность двух видов после деления пополам равна `h P_- W` для оригинала и противоположна ей для отражения. Поэтому внешний продукт этого вектора можно оценить для каждого вида по отдельности.

Корректируем средний внешний продукт по настоящим парам, прибавляя разность средних приближённых продуктов по непарным видам и по якорям. Это матричная контрольная вариата на основе действия учителя. В варианте с адаптивным весом оцениваем по якорям скалярный коэффициент регрессии настоящих продуктов на приближённые в норме Фробениуса. Отрицательные собственные значения после коррекции обнуляем и записываем долю удалённой спектральной массы. При стабильном распределении между якорями и независимыми непарными видами поправка с фиксированным весом центрирована до проекции на конус положительно полуопределённых матриц, если нормировка фиксирована. Принцип коррекции предсказанных величин по размеченной подвыборке связан с prediction-powered inference. [Angelopoulos и соавт., 2023](https://doi.org/10.1126/science.adi6000)

Сравниваем априоры с коррекцией, моделью учителя без коррекции, оценкой только по якорям и случайно повёрнутым проектором того же ранга. Эталон для ошибки использует настоящие пары всех левых кандидатов и якорей, в том числе скрытые пары. Основное сравнение использует нулевое пересечение кандидатов, 32 якоря и 20 целевых меток на класс. Базис строится по отдельной выборке. В остальных условиях оцениваем устойчивость к изменению доли пересечения.

```bash
python experiments/student_symmetry_calibration/partial_pairs.py --teacher-moments --seeds $(seq 401 412) --overlaps 0 .25 .5 1
python experiments/student_symmetry_calibration/plot_partial_pairs.py \
    --metrics experiments/student_symmetry_calibration/results/teacher_moments/metrics.json \
    --output experiments/student_symmetry_calibration/results/teacher_moments/curves.png
```

В повторе восстанавливаем стандартизованные признаки линейной ridge-регрессией на нечётные координаты. Регрессия видит только непарные маргинали и признаки якорей без их соответствий. В пространстве наблюдений оператор подгонки имеет спектр в интервале от нуля до единицы, поэтому не усиливает суммарную энергию стандартизованных признаков. Контроль того же ранга использует случайный базис вместо нечётных координат учителя. Повторяем исходные seed 401–412 и проверяем эффект на новых seed 413–424. Основной контраст на новых разбиениях сравнивает коррекцию с фиксированным весом с оценкой по якорям при нулевом пересечении.

## Выбор орбитального ограничения по чистой поддержке

Проверяем, можно ли подобрать силу ограничения на целевой задаче, имея только обычные изображения с метками. Строим исходное семейство априоров с остаточной относительной дисперсией орбит 100, 75, 50, 25 и 10%. Для каждого ограничения, кроме изотропного, создаём четыре случайных поворота того же спектра в белом базисе. Они образуют контроль ориентации. По целевым меткам сравниваем классическое маргинальное правдоподобие, его центрирование по перестановкам меток и ошибку исключения по одному чистому изображению. Выбор ядра по связи с метками родственен центрированному выравниванию ядер. Здесь мы сравниваем правдоподобие с контролем того же спектра. [Cortes и соавт., 2012](https://www.jmlr.org/papers/v13/cortes12a.html)

Для каждого бюджета вычитаем из его правдоподобия среднее правдоподобие повёрнутых априоров. Сравниваем этот контраст на настоящих метках и на 39 перестановках, сохраняющих числа примеров каждого класса. Стандартизуем контрасты по общему набору перестановок и выбираем бюджет с наибольшим положительным результатом. В консервативном варианте используем изотропный априор, если максимум недостаточно выделяется на уровне 0,10. Сравнение с максимумом по бюджетам выполняется на каждой перестановке. Тестовые метки и преобразованные изображения при подборе отсутствуют.

Основной контраст на 20 разбиениях CIFAR-10 сравнивает консервативный выбор с обычным маргинальным правдоподобием по парной точности при 20 метках на класс. Отдельные оценки измеряют точность на чистых изображениях и при поворотах на ±22°. Повороты отсутствуют при построении исходной ковариации, которая использует отражение. При фиксированном бюджете 25% и обычном орбитальном априоре сила не оценивается по целевой поддержке.
